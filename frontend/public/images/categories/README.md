# Directory category photos

Photos in this folder replace the emoji icons on the directory home page.
Filenames map to category ids (`<id>.webp`, 512×512, center-cropped); if a
file is missing, the emoji fallback is shown automatically.

The current set are openly-licensed placeholders sourced via Openverse.
**If the client supplies official photos, overwrite the files here — no code
change needed.** Keep this attribution table in sync (CC BY / CC BY-SA
require attribution).
