# Platform Administrative Coverage & Audit Matrix

## 1. Overview & Architecture
The Alanya Holidays Platform implements a declarative, zero-leak RBAC security architecture. All administrative operations are strictly encapsulated in domain-bounded NestJS controllers protected by `@UseGuards(AuthGuard, RolesGuard)` and `@RequireRole('admin')`.

No administrative action can bypass authentication or role evaluation. Each domain controller maintains dedicated administrative sub-routes (`/admin/*`) or dedicated admin controllers (`*-admin.controller.ts`) to prevent god-object anti-patterns.

## 3. Frontend Admin Integration
Frontend administrator UI (`frontend/src/pages/admin/`) communicates with all administrative endpoints through `frontend/src/api-services/admin.service.ts`:
- **Listings Moderation Tab (`ListingsModerationTab.tsx`)**: Moderates directory listings with filter matrix, bulk approval/rejection, and preview modals.
- **Claims Queue Tab (`ClaimsQueueTab.tsx`)**: Inspects ownership claims, verifies documentation, and triggers ownership transfer RPCs.
- **Concierge Tab (`ConciergeTab.tsx`)**: Manages enquiries, ticket assignment, and response workflows.
- **Content Moderation Tab (`ContentModerationTab.tsx`)**: Triages creator UGC submissions with live preview and rejection reasons.
- **Platform Analytics Tab (`PlatformAnalyticsTab.tsx`)**: Visualizes KPIs, trends, and channel performance using Recharts.

## 4. Verification & Attestation
All administrative controllers and routes are covered by automated unit test suites and end-to-end integration tests confirming:
1. Unauthorized requests (unauthenticated) receive HTTP `401 Unauthorized`.
2. Forbidden requests (authenticated non-admin) receive HTTP `403 Forbidden`.
3. Authorized requests (authenticated `admin`) succeed with HTTP `200 OK` / `201 Created`.
